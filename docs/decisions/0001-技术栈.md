# 0001 技术栈：Python + SQLite + 本地 Web
- 日期：2026-10-26
- 状态：部分被 [0003](0003-Android打包与Web框架.md) 取代（Web 框架、手机端方案）

## 背景
需要 Windows 上日常使用，Android 上离线可用，并能在局域网访问；单人开发。

## 决定
- 后端：Python 3.12 + SQLite，Web 层用 FastAPI（M1 起）。
- 前端：Vue 3 + Vite，构建为静态文件由后端托管。
- 手机端：Termux 运行同一套程序，浏览器访问，不另写原生 App。
- 下载器：gallery-dl 作为可选依赖。

## 理由与代价
- 一套代码三种用法（PC、手机离线、局域网），维护成本最低。
- 代价：手机端要装 Termux，体验不如原生 App；SQLite 不支持两端同时写（见设计文档第 8 节）。
- 待确认风险：FastAPI 依赖的 pydantic-core 是 Rust 扩展，在 Termux 上的安装方式需在 M1 前验证；不行就换纯 Python 的 Web 框架（如 Bottle）。
