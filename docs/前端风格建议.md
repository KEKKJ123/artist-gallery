前端风格建议

这个项目是**图片优先的本地工具**。界面应该退到背景里,让作品成为主角。

### 1. 整体风格

- **深色优先,同时提供浅色主题。** 中性深灰底(`#14151a` 左右),不要纯黑。深色背景下图片色彩更准,长时间看也不累。
- **低饱和、克制。** 全局只用一个强调色(比如柔和的紫或蓝),用于选中态、主按钮和 tag 高亮。
- **扁平、小圆角(4–8px)、少阴影。** 用 1px 细边框和明度差分层,不用重投影。
- **字体用系统字体栈**(`system-ui, "PingFang SC", "Microsoft YaHei"`),不要引入网络字体。Termux 和离线场景下会加载失败。

### 2. 图片展示(核心)

- **缩略图用瀑布流或等高行布局(justified)。** 画作比例差异大,固定正方形裁切会毁构图。至少要提供"原比例"和"方形"两个切换。
- **网格密度可调。** 用滑块或 `Ctrl+滚轮`调缩略图大小,并记住用户设置。
- **虚拟滚动**(如 `vue-virtual-scroller`)。图库量大时,DOM 节点数必须受控。
- **懒加载加占位。** 先按宽高比预留空间(数据库里存宽高),避免加载时页面跳动。可以用主色块或 blurhash 做占位。
- **悬停显示信息,默认不显示。** 默认只显示图片本身。悬停或选中时,在角落显示画师、页数徽标(`1/4`)和来源图标。

### 3. 收件箱和批量整理(M1 重点)

- **选中态要一眼可辨。** 用强调色描边加左上角对勾。多选时,顶部或底部弹出**浮动操作栏**,显示"已选 N 张 → 指定画师 / 加 tag / 归档"。
- **支持键盘。** 方向键移动,空格预览,`Ctrl+A` 全选,`Shift` 范围选,数字键或快捷键打 tag。批量整理的效率主要靠这个。
- **左右分栏。** 左边是网格,右边是可收起的详情和编辑面板。
- **操作可撤销。** 用 toast 加"撤销"按钮,别用确认弹窗,这样不会打断整理节奏。
- **大图预览用 lightbox。** 支持滚轮缩放、拖拽、左右切页,同一作品的多页要能连续翻。

### 4. 信息架构

- **左侧窄导航栏(可折叠)**:收件箱 / 浏览 / 画师 / Tag / 设置。手机端换成底部 Tab。
- **画师页要像"主页"。** 头像或代表作加名字、各平台账号链接、作品数,下面接作品网格。
- **Tag 用胶囊(chip)组件。** 按类别配色,但饱和度要低。支持输入时自动补全。
- **搜索栏全局固定。** 支持 `artist:xxx tag:yyy` 这种语法,并用 chip 展示已解析的条件。

### 5. 响应式(为 M4 提前设计)

- **从一开始就用移动优先的 CSS。** 用 `grid` 加 `clamp()`,不要写死像素宽度。
- **触控目标不小于 44px。** 长按进入多选(设计文档已有此项)。
- **用 CSS 变量管理主题和间距**(`--bg`、`--accent`、`--radius`、`--gap`)。这样换肤和手机适配都只需改变量。

### 6. 技术选型(契合 Vue 3 + Vite + Termux 约束)

| 用途   | 建议                                                                                      |
| ------ | ----------------------------------------------------------------------------------------- |
| 组件库 | **Naive UI** 或 **Element Plus** 的深色主题;想更轻量就手写 CSS 变量加少量组件 |
| 图标   | `lucide-vue-next` 或 Iconify 的离线打包版,不用 CDN                                      |
| 样式   | 原生 CSS 变量加 scoped style,或 UnoCSS/Tailwind(构建期生成,不影响手机端)                  |
| 状态   | Pinia;选中集合、缩略图大小这类 UI 状态放这里                                              |
| 资源   | **全部本地打包,不依赖 CDN**。要支持离线和局域网                                     |

### 7. 要避免的

- 营销页式的大图、大留白、渐变英雄区。这是工具,不是官网。
- 会遮挡图片的常驻浮层。
- 大量弹窗和二次确认。批量操作用撤销代替。
- 重动画。过渡控制在 150ms 以内,并尊重 `prefers-reduced-motion`。

### 建议的落地顺序

1. 先定 CSS 变量(颜色、间距、圆角)和深浅主题。
2. 做**网格加多选加浮动操作栏**。这是 M1 的核心组件,后面所有页面都复用它。
3. 再做 lightbox 和详情面板。
4. 最后加响应式适配。

需要的话,我可以按这个方向在 `frontend/` 里搭一个 M1 的骨架,包括主题变量、网格和多选组件。
